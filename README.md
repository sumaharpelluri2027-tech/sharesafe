# ShareSafe

Make your Mac safe to screen-share in one keypress: Do Not Disturb on, chat apps hidden, desktop clean. Press again and everything comes back.

- **Website:** https://sumaharpelluri2027-tech.github.io/sharesafe/
- **Download:** [ShareSafe.zip (latest release)](https://github.com/sumaharpelluri2027-tech/sharesafe/releases/latest/download/ShareSafe.zip)
- **Support / bug reports:** [open an issue](https://github.com/sumaharpelluri2027-tech/sharesafe/issues)

This repository hosts the website and release downloads. First launch: right-click ShareSafe → Open, or System Settings → Privacy & Security → Open Anyway (the app isn't notarized yet).
